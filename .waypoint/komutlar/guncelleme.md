# Waypoint update

Read this when I type `Waypoint'i güncelle`, a commit prints "Waypoint güncellemesi var", or a session starts with a newer version in `.waypoint/.son-surum`. `.waypoint/VERSION` is the installed version.

1. Read what changed: `https://raw.githubusercontent.com/1eren0/WaypointSkill/main/CHANGELOG.md`. If that fails (private repo), use `gh api repos/1eren0/WaypointSkill/contents/CHANGELOG.md -H "Accept: application/vnd.github.raw"`.
2. Summarize the versions newer than mine for me in plain words. If a commit message or session start started this, ask whether to install and never update without my OK. If I typed `Waypoint'i güncelle`, that is my OK: go on.
3. On OK, run `python .waypoint/hooks/kontrol.py --guncelle` yourself from the project folder (`python3` or `py -3` if `python` isn't found). It only downloads Waypoint's files and swaps them in; it runs nothing it downloaded. If it prints "Waypoint güncellendi", go to step 4. If it says "Güncelleme OLMADI", follow its message (it restores the old version itself): tell me the error in plain words. Never run the installer (`install.ps1` / `install.sh`, `guncelle.bat`) yourself, not even part by part: it runs code downloaded from the internet. Only if your tool blocks the command above or it doesn't exist, tell me to double-click `.waypoint/guncelle.bat` (macOS: `.waypoint/guncelle.command`) and to write "güncelledim" when it says it's done, then check that `.waypoint/VERSION` shows the new version.
4. Commit the result alone as `chore: update Waypoint to <version>`.
5. If the commit check names stray files in `.waypoint/`, move them as it says (old reports with `git mv` into `raporlar/`, dated by their last commit: `git log -1 --format=%as -- <file>`; anything else into the project, and tell me where). Commit that alone as `chore: move old reports into raporlar`.
6. If new checks block commits, fix what they say first.
7. If `HARITA.md` is in the old format (it has `## Şema` or `## Key functions / components`), rewrite it once: a `# Harita` title, the top comment from the current template (`https://raw.githubusercontent.com/1eren0/WaypointSkill/main/template/.waypoint/HARITA.md`), then `## Dosyalar` with at most ~30 lines `- path — what it does in plain words` (a folder ends with `/`) and `## Giriş noktaları` with at most ~20 lines `- name() — path — what it does — test: path`. Drop the diagrams, the uses/used-by lines and the not-mapped lists. Commit it alone as `docs: simplify the project map`.
